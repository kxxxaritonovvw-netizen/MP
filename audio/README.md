# Локальные треки

Положите сюда файлы:

- `kleopatri.mp3` — Пошлая Молли — Клеопатри
- `right-above-it.mp3` — Lil Wayne, Drake — Right Above It

Пути задаются в объекте `tracks` в `modal.js`. Используйте имена файлов латиницей. Поддерживаются MP3, M4A, OGG, WAV, FLAC (зависит от браузера и кодека).

Запуск: `node server.js`, затем http://127.0.0.1:4173. При открытии карточки музыка запускается, при закрытии останавливается. Элементы управления скрыты. Если браузер блокирует воспроизведение, попробуйте открыть карточку ещё раз.
