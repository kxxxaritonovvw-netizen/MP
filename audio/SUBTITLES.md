# Субтитры

В `audio/lyrics/` положите файл с тем же базовым именем, что у MP3 в `audio/tracks/`, и расширением `.lrc`. Кодировка UTF-8. Каждая строка: [минуты:секунды.сотые]Текст строки. Пустая строка с таймкодом скрывает субтитр во время паузы.

Отображаются три строки по центру модалки; перемотка синхронизирует текст. Для «Клеопатри» подключён предоставленный пользователем текст и пословные таймкоды, автоматически выровненные по локальной записи через faster-whisper small на CPU. Enhanced LRC использует маркеры `<mm:ss.xx>` перед словом и после него. Внутри каждого слова заливка интерполируется между его началом и концом; это не фонемная разметка отдельных букв.

Пословная разметка содержит 232 слова. У 11 слов границы короче 40 мс, преимущественно в повторяющемся бридже; нужна ручная проверка на слух. Нулевые интервалы не заменены вымышленными точными таймкодами.

Для `tracks/right-above-it.mp3` используется `lyrics/right-above-it.lrc`: 139 коротких продуктовых строк с пословными таймкодами. Текст очищен от разметки Genius, вступление и финальные служебные реплики исключены, воспроизведение начинается с первого куплета Drake. Салюты привязаны к спектральному акценту слова `love` в трёх доступных повторах припева.

Скрипты в `tools/audio/` воспроизводят подготовку. Папки `.audio-tools` и `.audio-models` нужны только для обработки и исключены из Git; браузер использует готовые файлы из `audio/tracks/` и `audio/lyrics/`.
